# GitHub Actions CI Demo

This repository demonstrates a simple Continuous Integration (CI) workflow using GitHub Actions.

## About
The workflow automatically runs whenever code is pushed to the repository. It uses a GitHub-hosted Ubuntu runner to execute a simple task and display a message in the workflow logs.

## Features
- GitHub Actions workflow
- Automatic workflow trigger on push
- YAML workflow configuration
- Simple CI example for beginners
